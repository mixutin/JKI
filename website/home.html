03 — THE CONTROLS STAY WITH YOU

Your voice.
Your call.

A helpful companion should make its boundaries clear. Jake is designed around visible choices, explicit approvals, and controls you can reach.

◉

Local speech processing

Wake-word detection, transcription, and speech synthesis run locally. Approved requests go to the Codex service.

⌘

Human decisions

Review transcripts and permission requests. Choose a restricted, workspace, or explicitly confirmed full-access profile.

Room to pause

04 — LET’S GET ACQUAINTED

A few commands.
A new way to work.

Jake is a development project for Linux. Bring Python 3.11+, the desktop dependencies, local speech models, and a compatible Codex App Server.

Follow the complete installation guide ↗
Built in the open.Native desktop and live Codex validation are still in progress. Start with the setup guide and validation checklist.
YOUR TERMINAL
git clone https://github.com/ridjan-xhika/JKI.git
cd JKI
python3 -m venv --system-site-packages .venv
. .venv/bin/activate
python -m pip install '.[audio]'
jki setup
jki doctor
jki run
